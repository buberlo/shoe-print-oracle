# Shoe Print Oracle

> Your footsteps consult a local deity and forecast today's tiny disasters.

The app records how you walk, stop, and turn, then distills the day's movement into a mythic forecast and a small ledger of footfall tokens. If you stand perfectly still too long, your shadow files for a nap and begins withholding directions.

## Features
- Core Motion step and heading capture, rendered as a private footprint map
- Local rule engine that turns pace, pauses, and U-turns into one daily oracle card
- Shadow nap system that pauses navigation and rewards you for resuming movement
- Token vault where unused footfall tokens can be donated to local myth entries

## Stack
- SwiftUI
- Core Motion
- GRDB
- MapKit

## Getting started
```
Open in Xcode, select an iPhone target, run on a device or simulator with motion/location permissions enabled, then walk, pause, and turn to generate the daily oracle card.
```
